### 🚚 LastMileIQ-SQL

A **SQL-only last-mile delivery intelligence project** modeling the complete delivery lifecycle.

```text
Customer
   ↓
Order
   ↓
Courier Assignment
   ↓
Pickup
   ↓
Route
   ↓
Multiple Stops
   ↓
Traffic / Distance
   ↓
Delivery Attempt
   ↓
Delivered / Failed / Returned
   ↓
Cost + Earnings + Performance
```

Analyzes courier performance, route efficiency, delivery delays, customer behavior, delivery risk, costs, and profitability.

**Technologies:** PostgreSQL · SQL

[View Project →](https://github.com/mahitech580/LastMileIQ-SQL)
