# 🚀 Featured Projects

## ✈️ TripPilot — Travel Planner

A responsive **travel planning web application** designed to bring trip organization into one place.

TripPilot allows users to **discover destinations, plan trips, choose transportation, create itineraries, find stays, manage budgets, prepare packing lists, and save trips locally**.

### Key Features

* 🌍 Destination discovery
* 🗺️ Trip planning with dates and travelers
* 🚌 Bus and other transportation options
* ✈️ Flight planning
* 🚆 Train planning
* 🚕 Cab / Auto options
* 🚇 Metro and Ferry options
* 📅 Day-by-day itinerary management
* 🏨 Stay finder
* 💰 Trip budget calculation
* 🎒 Packing checklist
* 🧳 Save and manage trips
* ⚙️ Travel preferences
* 💾 LocalStorage persistence
* 📱 Responsive interface
* 🌐 GitHub Pages deployment

**Tech Stack:** HTML5 · CSS3 · JavaScript · LocalStorage

🔗 **Repository:**
https://github.com/mahitech580/TripPilot-Travel-Planner

🌐 **Live Demo:**
